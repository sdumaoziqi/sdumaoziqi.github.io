# SAM(Sharpness-Aware Minimization)优化器详解

## 1. 算法原理

SAM优化器是一种旨在同时最小化损失值和损失锐度的优化算法。其核心思想是通过在参数空间中进行扰动来寻找平坦的最小值区域，从而提升模型的泛化能力。

算法每次迭代包含两个关键步骤：
1. **扰动步骤**：计算梯度并沿着梯度方向添加扰动
2. **优化步骤**：回到原始参数位置执行实际优化

## 2. 代码实现分析

从`_code/sam/sam.py`的实现可以看出：

```python
class SAM(torch.optim.Optimizer):
    def __init__(self, params, base_optimizer, rho=0.05, adaptive=False, **kwargs):
        # 初始化参数
        self.base_optimizer = base_optimizer(self.param_groups, **kwargs)
        
    def first_step(self, zero_grad=False):
        # 计算梯度范数并添加扰动
        p.add_(e_w)  # 向局部最大值方向移动
        
    def second_step(self, zero_grad=False):
        # 返回原始参数位置并执行基础优化器步骤
        self.base_optimizer.step()
```

## 3. 核心参数

| 参数 | 说明 |
|------|------|
| base_optimizer | 基础优化器(如SGD, Adam等) |
| rho | 控制扰动大小的超参数 |
| adaptive | 是否使用自适应版本 |

## 4. 使用示例

```python
# 初始化
base_optimizer = torch.optim.SGD
optimizer = SAM(model.parameters(), 
               base_optimizer, 
               lr=0.1, 
               rho=0.05)

# 必须提供closure函数
def closure():
    optimizer.zero_grad()
    loss = loss_function(model(input), target)
    loss.backward()
    return loss

# 训练步骤
optimizer.step(closure)
```

## 5. 优势与特点

1. **提升泛化能力**：通过寻找平坦的最小值区域
2. **灵活性**：可与各种基础优化器结合使用
3. **自适应版本**：考虑参数大小的自适应扰动

## 6. 注意事项

1. **计算开销**：比普通优化器大约多一倍
2. **参数调整**：需要仔细调整rho参数
3. **必须提供closure**：不同于常规PyTorch优化器
